# じょぶはん Windows版ダウンロードサイト

Figmaの「じょぶはん｜Windows版ダウンロードサイト」画面をもとにした、独立した静的フロントエンドです。レイアウトと色はFigmaに合わせ、ヒーローの登場、スクロール連動のフェードイン、カードの浮き上がりを加えています。画面幅に合わせてレイアウトが切り替わります。

## 起動

Node.js 18 以降を使い、プロジェクトフォルダーで npm run dev を実行します。

ブラウザーで http://127.0.0.1:4173 を開きます。追加パッケージは不要です。

## Windowsインストーラーの配置

このフォルダーには配布用 .exe は含まれていません。最終版を downloads/jobuhan-setup.exe に配置すると、ページ上のダウンロードボタンから配布できます。ファイルが未配置の間は、ボタンを押すと準備中の案内を表示します。

## 主なファイル

- index.html — ページ構造と日本語コピー
- styles.css — Figmaの配色、レスポンシブレイアウト、アニメーション
- main.js — フェードイン、モバイルメニュー、FAQ、ダウンロードボタン
- assets/ — Figmaから取得したSVG素材
